ABSTRACT

Pose-based gait data are widely used for clinical screening, yet whether Large Language Models (LLMs) can interpret such motion evidence remains underexplored. We introduce GaitEval, a six-dataset benchmark for evidence-grounded label prediction across ASD-Kinect, ATAXIA, CARE-PD, GMFCS, PARKINSONISM, and PATHOGAIT, with heterogeneous populations, pose formats, and label spaces. A baseline-anchored protocol compares controlled pose-derived inputs with label-prior and same-feature linear references, and evaluates zero-shot, few-shot, and low-rank adaptation (LoRA) within their tested coverage. Five-model motion-summary results show limited zero-shot agreement on most tested tasks, while six-dataset Qwen2.5-7B comparisons with source-reported subject-disjoint splits identify important dataset–representation exceptions. Linear references recover task-relevant signal where available, while adaptation recovers some in-distribution mappings: GMFCS summary macro-F1 in the shared-condition evaluation rises from 0.265 to 0.467, but remains below its matched linear reference of 0.579. The ATAXIA adaptation experiment likewise shows an agreement increase from κ = 0.046 to 0.507; transfer remains unreliable in the tested bidirectional ATAXIA–PATHOGAIT probe. Overall, evidence use is heterogeneous and representation-dependent: adaptation can learn dataset-specific mappings, while reliability beyond the tested settings remains unresolved.

01 / BENCHMARK

Different populations.
One controlled question.

Each dataset keeps its native task. Patient cohorts, imitated gait, and simulated gait are described separately; none is treated as an interchangeable clinical diagnosis.

02 / METHOD

Hold the evidence fixed.
Change how it is used.

Derive interpretable measurements from valid pose frames. Render one evidence view, redact answer-revealing metadata, and compare LLM predictions with linear classifiers using the same feature columns.

1

Signal availability

Matched logistic regression and a linear SVM probe recoverable supervised signal.

2

Evidence responsiveness

No-evidence, shuffled-evidence, and candidate-order controls test Qwen2.5-7B zero-shot motion-summary sensitivity across all six datasets.

3

Adaptation boundaries

Dataset-specific LoRA tests in-distribution recovery. Additional few-shot and transfer probes retain their measured scope.

Four input-view families; z-scoring is a scaling control within named features. The shared six-dataset matrix uses summaries and z-features.
