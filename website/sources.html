Sources & attribution

Examples illustrate source resources and are not paired with evaluated predictions. No image is supplied to the language models.

  • ASD-Kinect: original recorded skeleton video, Dataset/Autism/children with ASD/1/video/Svideo.avi, frame at 0.5 seconds. Al-Jubouri et al. dataset record.
  • ATAXIA: captured-video examples from Khalil et al., Diagnosis of Cerebellar Ataxia Based on Gait Analysis Using Human Pose Estimation (2022), DOI 10.1109/IECBES54088.2022.10079396. Dataset (CC BY 4.0). Source-paper image reuse terms require confirmation before final distribution.
  • CARE-PD: cropped input-gait mesh example from the official benchmark figure. Adeli et al., NeurIPS 2025; dataset terms CC BY-NC 4.0. No identifiable RGB footage.
  • GMFCS: newly rendered skeleton from source-repository demo keypoints, input_000000000060_keypoints.json, Kidziński et al.. This is a source demo, not a confirmed benchmark test participant. The source trajectory terms differ from the Apache code license; no original demo RGB video is redistributed.
  • PARKINSONISM: cropped source-publication recording example from Deng et al., npj Parkinson's Disease 10, 122 (2024), DOI 10.1038/s41531-024-00742-x, CC BY 4.0. No ground-truth severity is inferred from appearance.
  • PATHOGAIT: rendered recorded joints from Jun et al. source repository. No blanket data license was supplied; source permission for redistributed derived examples should be confirmed.

Vector diagrams are newly drawn. Decorative traces are schematic, not patient measurements. Dataset provenance, release boundaries, and remaining permission checks are retained in the camera-ready preparation audit.
