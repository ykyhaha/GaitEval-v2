# Project website

The public project is https://ykyhaha.github.io/GaitEval-v2/. Edit `index.template.html`, `style.css`, `app.js`, or `sources.html` here, then run `python3 scripts/build_website.py`. The builder refreshes current paper/figure/result/citation assets in `website/dist/` and mirrors them to `docs/`, the existing GitHub Pages source. It never rewrites the manuscript or runs a model.
